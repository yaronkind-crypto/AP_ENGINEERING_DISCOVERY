# AP Engineering Discovery

## Mission

The purpose of this repository is to discover, validate, preserve and evolve engineering knowledge derived from real engineering evidence.

This repository is **not** centered around the HTML generator.

The HTML generator is one consumer of the engineering knowledge.

Future AI agents, regression tools and engineering utilities will consume the same engineering knowledge.

---

## Engineering Philosophy

Reality comes first.

Engineering knowledge is always derived from validated engineering evidence.

Evidence may come from:

- Engineering Orders (PDF)
- ZIP / CSV topology
- Validated field cases
- Production observations
- Regression results

Engineering Assets are derived from evidence.

They are never the source of truth.

---

## V27 Mission

Discover.

Inventory.

Classify.

Document.

Do not change runtime behavior.

Do not invent new engineering rules.

Understand what the system already knows.
